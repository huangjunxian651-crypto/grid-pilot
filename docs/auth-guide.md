# GridPilot 账户系统操作指南

## 1. 注册

GridPilot 采用单管理员模式。首次使用时，点击登录页的"创建工作区 →"进入注册模式，填写邮箱和密码后点击"创建账号"。

注册时，系统会自动将当前界面语言保存为用户偏好。首次访问时，界面语言会根据浏览器默认语言自动选择。

## 2. 登录

在登录页输入邮箱和密码，点击"登录 GridPilot"。登录成功后自动跳转到 Dashboard。

会话通过 `gridpilot_session` Cookie 维持，有效期 7 天。

## 3. 查看账号信息

### 通过 Web 界面

登录后进入 **设置 → 账户资料**，页面下方"账号信息"区域会显示当前登录邮箱。这是系统唯一的账号标识。

### 通过服务器脚本

在服务器端执行查询脚本：

```bash
cd apps/api
npx ts-node scripts/list-users.ts
```

输出示例：
```
Found 1 user(s):

  [1] admin@example.com
      ID:            cmpxxx...
      Display Name:  (empty)
      Language:      zh
      Created:       2026-05-26T08:06:47.956Z
      Updated:       2026-05-26T09:34:36.775Z
```

## 4. 修改账号信息

登录后进入 **设置 → 账户资料**，可以修改以下内容：

- **显示名称**：您的显示昵称
- **邮箱**：管理员联系邮箱

修改后点击"保存"即可生效。邮箱修改后，下次登录请使用新邮箱。

## 5. 修改密码

登录后进入 **设置 → 安全**，输入当前密码和新密码（至少 8 位），点击"更新密码"。

## 6. 重置账号（管理员脚本）

GridPilot **不支持邮箱找回密码**。如需更换管理员邮箱或忘记密码，由服务器管理员在服务端执行重置脚本：

```bash
cd apps/api
npx ts-node scripts/reset-account.ts <新邮箱> <新密码>
```

示例：
```bash
npx ts-node scripts/reset-account.ts admin@example.com NewSecurePass123!
```

**注意：**
- 此脚本会直接重置系统中唯一的管理员账号的邮箱和密码
- 不需要知道原邮箱或原密码
- 重置后请使用新邮箱和新密码登录
- 已存在的活跃会话（Redis 中）在过期前（7 天）仍然有效。如需立即强制登出所有会话，请重启 API 服务或清除 Redis

## 7. 语言切换

### 登录前
首次访问时，系统根据浏览器语言自动选择界面语言。支持中文（简体/繁体）、英文、日文、韩文等 12 种语言。

### 登录后
进入 **设置 → 外观**，点击语言选项即可切换。语言偏好会自动保存到用户资料，下次登录自动恢复。

## 8. 会话管理

- 会话存储在 Redis 中，有效期 7 天
- 点击侧边栏用户头像处的"退出登录"可立即销毁会话
- 未认证用户访问任何页面都会自动重定向到登录页

## 9. 安全建议

- 密码至少 8 位，建议包含大小写字母、数字和符号
- API 密钥在服务器端经 AES-256-GCM 加密存储
- 仅授予交易所 API "读取 + 交易"权限，**永远不要授予提币权限**
